# net

Computer networking labs in C++ covering UDP/TCP clients, servers, and protocol-level experiments.

## Overview

This repository contains several practical networking assignments focused on client-server communication, transport protocols, and related experiments.

## Structure

- `lab1` - introductory networking assignment
- `lab2` - additional protocol-level exercise
- `lab3` - networking coursework task
- `lab4` - advanced or final lab in the set

## Stack

C++, sockets, platform-specific build files.

## Notes

This repository is organized as a set of academic networking labs.
